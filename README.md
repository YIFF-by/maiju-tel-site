# 麦橘 TEL 官网

官网：https://yiff-by.github.io/maiju-tel-site/

本仓库保存可直接运行的静态网站，GitHub Pages 从 `main` 分支根目录发布。
网页、图片、字体和视频分片均在本仓库中，不依赖原预览站提供资源。

## 内容与维护

- `index.html`：首页；`about.html`：关于我们。
- `magic-studio.html`：Magic Studio；`contact.html`：合作联系。
- `works/`：六个视频栏目及作品页面；`style.css`、`app.js`：样式与交互。
- `assets/streaming/`：首页与关于页视频，保留现有 HLS 播放方式。
- 页面内部链接以 `/maiju-tel-site/` 开头；如更换仓库名或域名，需同步调整链接与站点地图。

修改后提交并推送到 `main`，GitHub Pages 将自动重新部署。
视频与作品内容归麦橘 TEL 或对应权利人所有；第三方字体与播放器许可见对应 assets 目录。
